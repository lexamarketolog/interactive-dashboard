# Interactive Analytics Dashboard

Интерактивный веб-дашборд с живым редактированием, совместной работой и прогнозированием. Сделан с нуля за одну сессию в Claude Code из Excel-отчёта.

## Что умеет

- **Живое редактирование** — меняешь цифру, графики перестраиваются сразу
- **Связанные поля** — изменяешь расход, клики пересчитываются через CPC
- **Goal-seek** — задаёшь целевой ROMI/ДРР, расход считается назад
- **4 графика** — Расход/Доход, Показы/Клики, ROMI/ДРР, Покупки/CPO
- **Прогноз** — добавляешь строки будущих месяцев, на графиках пунктир
- **Совместная работа** — несколько человек редактируют одновременно через WebSocket
- **История изменений** — 20 шагов Ctrl+Z / Ctrl+Y, откат виден всем
- **Строка итогов** — суммы и взвешенные средние, прилипает при прокрутке
- **MoM-дельты** — стрелки ↑23% / ↓8% рядом с ключевыми показателями
- **Экспорт CSV** — скачать данные текущего бренда
- **Пароль** — экран входа с кодом доступа

## Запуск локально

```bash
npm install
node server.js
# открыть http://localhost:8799
```

## Docker

```bash
docker build -t dashboard .
docker run -p 8799:8799 dashboard
```

## Стек

- Vanilla JS + HTML — никаких фреймворков
- Node.js + ws — WebSocket-сервер для совместной работы
- Chart.js 4 — графики
- Docker — деплой
